now in terminal type `uv init` - it will create all required things for development
now for virtual environment `uv venv` - it will create it with project/repo name - so venv = repo name
for custom virtual environment `uv venv <any name for venv>` - <any name for venv> is your venv

for add package ` uv add ___ ___ ___ ___ ___` - it add all package you type
